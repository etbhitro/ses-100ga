# СЭС 100 га · Иссык-Куль

3D-модель солнечной электростанции на склонах Кунгей Ала-Тоо (Кара-Ой → Чолпон-Ата) на реальном рельефе.

Сайт: https://etbhitro.github.io/ses-100ga/

- Вход по паролю — это заставка, а не защита: код страницы открыт.
- Нужен интернет: three.js (esm.sh), рельеф (AWS Terrain Tiles), снимки (Esri World Imagery). Первая загрузка 30–60 с.
- Подпись «Снимки © Esri, Maxar · Рельеф © AWS Terrain Tiles» — условие использования данных, не убирать.
