# СЭС 100 га · Иссык-Куль / 100公顷光伏电站 · 伊塞克湖

3D-модель солнечной электростанции на склонах Кунгей Ала-Тоо (Кара-Ой → Чолпон-Ата) на реальном рельефе.

Сайт: https://etbhitro.github.io/ses-100ga/ (китайская версия сразу: `?lang=zh`)

- Языки: русский и китайский, переключатель RU / 中文 на экране входа и на панели.
- Координаты (широта/долгота, градусы и десятичные) для центра массива, сёл и участков 01–03; кнопка «Открыть в Google Maps» и копирование.
- Центр массива: 42.673527, 77.065068 (42°40′25″ с. ш., 77°03′54″ в. д.).
- Вход по паролю — это заставка, а не защита: код страницы открыт.
- Нужен интернет: three.js (esm.sh), рельеф (AWS Terrain Tiles), снимки (Esri World Imagery). Первая загрузка 30–60 с.
- Подпись «Снимки © Esri, Maxar · Рельеф © AWS Terrain Tiles» — условие использования данных, не убирать.
